# 🎨 Python Rangoli

A rangoli pattern generator built with Python.

![Rangoli Output](<img src "python-rangoli.png" alt="python-rangoli" width="350">)

## ✨ Features

- Draws a colorful rangoli pattern using code
- Uses loops and functions to create repeating shapes
- Easy to change colors, size, and pattern

## 🛠️ Built With

- Python 3
- `turtle` module

## 🚀 Run Locally

```bash
git clone https://github.com/suryajeet940/python-rangoli.git
cd python-rangoli
python rangoli.py
```

## 📚 What I Learned

- Using loops to create patterns
- Writing reusable functions
- Working with colors and coordinates
